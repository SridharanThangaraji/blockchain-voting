# Technology Stack – Review 1

The following technologies were used to implement the Review-1 prototype of the blockchain-based voting system:

| Layer        | Technology Used                 | Purpose |
|-------------|----------------------------------|---------|
| Blockchain  | Solidity, Hardhat                | Development, compilation, and deployment of smart contracts |
| Backend     | Node.js, Express.js, ethers.js   | Interaction between frontend and Ethereum blockchain |
| Frontend    | HTML, CSS, JavaScript            | User interface for casting votes and viewing results |
| Wallet      | Hardhat Local Accounts           | Simulated blockchain accounts for testing |
| Network     | Ethereum Local Network (Hardhat) | Local blockchain environment |
| Hosting     | Localhost                        | Hosting frontend and backend services |

---

### Notes

- Review-1 focuses on demonstrating blockchain feasibility and integration.
- Voting operations are verified primarily through terminal-based testing.
- Advanced security, authentication, and production deployment are planned for future reviews.
