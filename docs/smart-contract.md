# Smart Contract Explanation – SimpleVoting

A smart contract is a program deployed on the blockchain that executes automatically when conditions are met.

The SimpleVoting smart contract allows voters to cast votes for predefined candidates. Each vote increases the candidate’s vote count and emits an event called VoteCast, which is permanently recorded on the blockchain.

This contract demonstrates immutability, transparency, and decentralization, which are key advantages of blockchain-based voting systems.
