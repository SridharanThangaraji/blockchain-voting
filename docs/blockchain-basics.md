# Blockchain Basics (Review-1)

Blockchain is a decentralized and distributed digital ledger that records transactions in a secure and immutable manner. Each block contains a list of transactions and is linked to the previous block using cryptographic hashing.

In this project, blockchain is used to store voting data securely. Once a vote is cast and recorded on the blockchain, it cannot be altered or deleted, ensuring transparency and trust in the election process.

Ethereum is a popular blockchain platform that supports smart contracts, which are self-executing programs stored on the blockchain.
